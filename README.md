# snow-miku

Claude 데스크톱 앱의 대화 배경을 눈 내리는 겨울밤으로 바꾸는 모드입니다. 창 오른쪽에 2019 스노우 프린세스 유키미쿠와, 맥북으로 일하는 Clawd 가 함께 있습니다.

- 어두운 얼음빛 색 테마가 함께 들어 있습니다.
- `/snow-off` 로 끄고 `/snow-on` 으로 다시 켭니다.
- 데스크톱·모바일 앱에서만 보입니다. 터미널에는 배경이 없습니다.

## 설치

터미널의 Claude Code 프롬프트에서:

```
/plugin install snow-miku --marketplace conlabx1/snow-miku
```

셸에서:

```bash
claude plugin install snow-miku --marketplace conlabx1/snow-miku
```

데스크톱 앱에서는 `/plugin` 이 안 되므로, 프롬프트 상자 옆 + → Plugins → Add marketplace 에 `conlabx1/snow-miku` 를 넣고 Add plugin 을 누릅니다.
